# Codex

[[Codex]] 是一个 AI Agent 产品，能通过自然语言指令完成任务。

## 核心功能

以下功能来自 [[全网最全，50分钟全面掌握新版Codex]] 视频简介：

- 能自己搭网站
- 图片能直接批注修改
- 一条指令同时开多个任务并行干活
- 接上[[飞书]]和钉钉做自动化
- 用 Hook 拦截高危操作
- 一键部署上线
- 持久记忆
- CLI 接飞书钉钉
- 插件 Skill [[MCP]] 自动化

## 与 Obsidian 的联动

来自 [[Codex联动Obsidian搭建卡帕西同款知识库]]：

- Obsidian 安装 Codex 插件，输入 Codex CLI 路径即可打通
- Codex 直接读取本地 Markdown 文件，无需手动整理
- 项目工作按钮可链接 Obsidian 仓库文件夹，处理文件时两边同步更新
- 自动化功能可设置定时任务（如每天下午五点自动蒸馏）
- 可写 Skill 定制专属工作流
