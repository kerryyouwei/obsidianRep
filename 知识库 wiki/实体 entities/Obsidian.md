# Obsidian

Obsidian 是一个本地 Markdown 笔记工具，AI 可以直接读取本地的 Markdown 文件。拥有强大的插件生态。

## 核心特点

来自 [[Codex联动Obsidian搭建卡帕西同款知识库]]：

- 本地 Markdown 文件，AI 可直接读取
- 插件生态丰富，可根据需要自由组合
- 第三方插件可关闭安全模式后从插件市场安装

## 常用插件

- **Codex 插件**：连通 Codex，AI 直接读取仓库文件
- **Web Clipper**：网页剪藏，选中内容段落即可收藏进 Obsidian
- **小红书导入插件**：粘贴链接一键导入
- **Importer**：支持 Notion、Apple Notes 等多平台导入
- **Presentations**：一键生成 PPT
- **HyperPerformance**：一键生成视频
