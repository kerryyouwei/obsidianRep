## 摘要

本视频介绍如何用 [[Codex]] 和 [[Obsidian]] 搭建 [[安德烈·卡帕西 Andrej Karpathy]] 同款[[自生长知识库]]。核心理念：不要把知识库当收藏夹，而是变成一个由 AI 持续维护的自生长系统。

### 系统循环

1. **原始资料**（文件夹 A）：网页、论文、截图、视频、会议纪要等统一进入
2. **AI 消化**（文件夹 B）：AI 定期消化复盘，把有价值的内容整理成泛化性概念
3. **Skill 库**（文件夹 C）：根据任务沉淀成可复用的方法论模板
4. **输出**（文件夹 D）：每次输出放在这里，定期复盘时回流进知识库

### 搭建步骤

- **安装配置**：需要 Codex 和 Obsidian 两个软件。Obsidian 是本地 Markdown 笔记工具，AI 可直接读取本地 Markdown 文件。在 Obsidian 中启用第三方插件，安装 Codex 插件，输入 Codex CLI 路径打通。
- **信息收集**：将 GitHub 资讯聚合项目地址发给 Codex，配置 API 密钥，设置身份和需求，AI 每天自动抓取信息、筛选重点、生成日报。可用 Obsidian 插件（如小红书导入、Web Clipper）直接收藏网页内容。
- **迁移旧资料**：通过飞书 CLI 导入飞书文档，用 Importer 插件导入 Notion、Apple Notes 等平台的内容。
- **知识迭代**：把[[安德烈·卡帕西 Andrej Karpathy|卡帕西]]的思路丢给 Codex，定制知识迭代系统。
- **自动化**：用 Codex 的自动化功能设置定时任务（如每天下午五点自动蒸馏），生成总结文件。
- **Skill 定制**：DIY 专属 skill（如选题价值判断、文风、去 AI 味、配图）管理知识库。

### 输出形式

文字稿、PPT（Presentations 插件）、视频（HyperPerformance 插件）、配图（自动生图插入）都可一键完成。

## 金句

> 以前用 AI 就像临时找外包，你讲一遍背景他干一次活。但当你的资料和方法论都沉淀在 Obsidian 里，AI 就能读到过去的积累，也能直接把产出放回系统。
