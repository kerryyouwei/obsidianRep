# 实盘验证试盘洗盘

> [!warning] 学习与风险边界
> 本笔记用于学习市场博弈、量价与复盘方法，不构成投资建议。市场中不存在从公开图表稳定识别“庄家意图”的保证；任何真实交易都应使用模拟验证和固定风险预算。

## 这一讲到底在解决什么问题

**一句话概括：** 在真实走势中检验试盘与洗盘假设，关注位置、量价、跟随和失败。

本讲把“庄家”视为一种分析视角，而不是可以被精准读心的实体。核心流程是：市场状态 → 供需与行为证据 → 情景假设 → 触发与失效 → 风险管理 → 复盘。

## 知识框架

1. **背景：** [[洗盘|洗盘]]与市场参与者的目标、约束和信息差。
2. **识别：** 从价格、成交量、盘口、区间和跟随寻找证据。
3. **应对：** 等待确认，设计入场、止损、目标和仓位。
4. **验证：** 用历史案例和实盘记录检验，而不是事后编故事。

知识链：`参与者与约束 → 供需/价格行为 → 阶段或形态 → 情景计划 → 风险边界 → 复盘`

## 核心知识

### 1. 先观察可见证据

在真实走势中检验试盘与洗盘假设，关注位置、量价、跟随和失败。 不是预测某个神秘角色下一步做什么，而是用可重复的图表信息提出概率假设。至少要记录：位置、趋势或区间背景、价格反应、成交量变化、突破后跟随，以及与假设相反的证据。

### 2. 把“故事”变成条件

本讲内容可转化为四类问题：

- **状态：** 当前更像趋势、吸筹/派发假设，还是普通震荡？
- **证据：** 哪些价格与成交行为支持假设？哪些只是叙事？
- **触发：** 什么收盘、突破、回踩或跟随才允许行动？
- **失效：** 哪个条件出现后，必须承认原判断不成立？

### 3. 与前后内容的连接

本讲承接裸K、交易区间和指标篇，向后连接威科夫、量价分析及交易系统。它不能替代止损、仓位与订单管理；所谓“看懂庄家”最终仍要落到可执行、可退出的计划。

> [!warning] 容易卡住
> “洗盘”“吸筹”“出货”等词容易变成事后标签。相同的价格行为可能有多个解释，必须保留替代情景，并等待后续跟随验证。

### 应用题

3. 看到区间下沿快速下破后又收回，你会如何提出两种情景，并分别写出确认与失效条件？

### 反思题

4. 回顾一次你用“庄家意图”解释行情的判断：哪些是当时可见证据，哪些只是事后故事？

> [!question]- 点击查看参考答案
>
> ### 基础题答案
>
> 1. 本讲围绕“在真实走势中检验试盘与洗盘假设，关注位置、量价、跟随和失败。”展开，重点是把博弈视角转化为证据、条件和风险边界。
> 2. 单根K线的量价信息缺少位置、前后文和跟随确认；它可能是突破、止损潮、消息冲击或普通波动，不能直接命名。
>
> ### 应用题答案
>
> 3. 情景A：下破是假突破并回到区间，确认是回收后出现持续跟随，失效是再次跌回区间下方；情景B：下破是真突破，确认是收盘和后续卖压延续，失效是快速收回并站稳区间内。
>
> ### 反思题答案
>
> 4. 把判断拆成“当时看到的价格/成交/位置”和“后来为了说明结果添加的解释”，只用前者检验规则，才能避免叙事偏差。
