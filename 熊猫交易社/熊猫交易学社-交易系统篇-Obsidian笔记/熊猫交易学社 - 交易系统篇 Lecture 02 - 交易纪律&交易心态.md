# 交易纪律&交易心态

> [!warning] 学习与风险边界
> 本笔记用于学习交易系统与风险管理，不构成投资建议。任何真实交易都可能造成损失；仓位、止损和纪律必须先在历史数据或模拟盘中验证。

## 这一讲到底在解决什么问题

**一句话概括：** 纪律和心态的目标不是压抑情绪，而是在不确定环境中持续执行已验证的规则。

交易系统的主线是：交易假设 → 信号与触发 → 风险预算 → 订单管理 → 复盘迭代。不能只记“进场信号”，还要定义什么时候不做、何时退出以及如何评估。

## 知识框架

1. **前置：** 市场状态、价格行为和个人风险承受能力。
2. **核心：** 交易纪律与交易心态。
3. **执行：** 入场、仓位、止损、止盈和纪律。
4. **验证：** 通过交易日志和一组样本评估系统，而不是由单笔盈亏下结论。

知识链：`假设 → 条件 → 仓位/风险 → 执行 → 退出 → 统计复盘`

## 核心知识

### 1. 规则必须可执行

纪律和心态的目标不是压抑情绪，而是在不确定环境中持续执行已验证的规则。 规则至少要回答：什么情况下入场？风险多少？止损放在哪里？目标和退出如何定义？哪些情况直接放弃？如果规则只能靠“感觉”，就无法稳定复盘。

### 2. 风险先于收益

仓位不是越大越好，纪律也不是盲目坚持。应先确定单笔风险预算，再结合止损距离和波动调整头寸；当市场状态、情绪或信息不符合计划时，最好的动作可能是不交易。

### 3. 与前后内容的连接

本讲承接裸K、指标、订单管理和交易心理，最终把它们收束成系统化流程。系统的价值在于减少临场自由裁量，同时保留对失效条件和异常风险的处理能力。

> [!warning] 容易卡住
> “系统有效”不等于每次都盈利；“严格执行”也不等于拒绝修正。应先按版本稳定执行，再用足够样本检验统计结果，最后记录规则变更。

## 自测题

### 基础题

1. 本讲的核心主题是什么？
2. 为什么交易系统必须包含风险和退出规则，而不只是入场信号？

### 应用题

3. 如果账户风险预算固定，但止损距离变大，你会如何调整仓位？请说明原因。

### 反思题

4. 回顾最近一次交易：哪一条规则在入场前不够明确，导致了临场决策？

> [!question]- 点击查看参考答案
>
> ### 基础题答案
>
> 1. 本讲围绕“交易纪律与交易心态”展开，重点是把分析、风险和执行连接成可重复流程。
> 2. 没有风险和退出规则，系统无法控制损失，也无法在样本中比较不同交易的执行质量。
>
> ### 应用题答案
>
> 3. 在单笔风险预算不变时，止损距离变大应相应减小仓位，使“仓位 × 止损距离”仍不超过风险上限；实际还要考虑滑点和波动。
>
> ### 反思题答案
>
> 4. 找出模糊的条件，把它改写成可观察的触发、失效和管理动作，并在后续样本中验证是否减少临场修改。
