# 第5讲：订单块（上集）

> [!warning] 学习与风险边界
> 本笔记用于学习订单流与市场结构，不构成投资建议。SMC、流动性、订单块和FVG都是概率性分析工具，不能保证预测结果；真实交易必须先模拟验证、控制仓位并设置失效条件。

## 这一讲到底在解决什么问题

**一句话概括：** 本讲围绕 **订单块类型与性质**，把订单流术语转成可观察的市场结构、价格反应和交易计划条件。

订单流学习主线是：流动性与结构 → 供需与订单块 → 不平衡/FVG → 多周期情景 → 触发与风险 → 系统化复盘。

## 知识框架

1. **基础：** [[订单块|订单块]]与市场结构、主动买卖和价格反应。
2. **核心：** 订单块类型与性质。
3. **验证：** 看形成背景、离开力度、回测、跟随和失效，而不是只看名称。
4. **应用：** 将观察转成入场、止损、目标、仓位和复盘规则。

知识链：`流动性/背景 → 结构与区域 → 价格反应 → 触发 → 风险管理 → 复盘`

## 核心知识

### 1. 先定背景与结构

先看形成背景、离开与回测，再判断类型。 任何区域或缺口都必须放在更大周期、趋势/区间和关键高低点中解释。价格是否快速离开、是否回测、是否形成持续跟随，通常比标签本身更重要。

### 2. 区分观察线索与交易信号

记录以下问题：

- 流动性位于哪里，谁可能被迫交易？
- 区域/订单块/FVG如何形成，离开是否有力度？
- 回测后是接受、拒绝还是直接穿越？
- 什么条件确认主情景，什么条件确认替代情景？
- 止损、目标、仓位和放弃条件是否提前明确？

### 3. 与前后内容的连接

本讲承接裸K、庄家思维、量价和交易系统，向后连接订单流策略与价格行为融合。订单流不能替代风险管理，也不能用“机构意图”解释所有波动。

> [!warning] 容易卡住
> “扫流动性”“订单块”“FVG”等词很容易成为事后叙事。相同价格行为可能有多个解释，必须保留替代情景，并等待后续价格反应验证。

### 反思题

4. 回顾一次订单流判断：你是否把“看起来像机构行为”当成了可验证证据？

> [!question]- 点击查看参考答案
>
> ### 基础题答案
>
> 1. 本讲围绕“订单块类型与性质”展开，重点是把订单流视角落到结构证据和风险边界。
> 2. 因为区域名称缺少形成背景、位置、离开力度和后续跟随；只有结合确认与风险收益，才可能成为交易候选。
>
> ### 应用题答案
>
> 3. 情景A：扫高后拒绝并向下延续，确认是收回后出现卖压跟随，失效是重新站回高点；情景B：扫高后接受并向上突破，确认是收盘与回踩站稳，失效是跌回区间。
>
> ### 反思题答案
>
> 4. 把判断拆成可见的价格、成交、位置、结构和跟随证据，另列替代解释；无法观察或无法验证的“机构意图”只能作为假设。
