@chkVchQuota
这个为额度对账凭证管理类的后端所有操作；  
帮忙在前端 [ibf-oper-web-container](ibf-oper-web-container/) 页面找一下对应的页面操作

上传一个820.sql
根据这个表，生成新的操作包括前后端，后端直接参考 [chkVchQuota](backend/ibf-oper-bootweb-fatp/bootWeb-mctp/src/main/java/com/adtec/mctp/chk/chkVchQuota/) 这个，保持结构一致；前端也直接参考`...\views\mctp\chkMng\2504.vue`；  
前端页面条件为：  
（1）开始日期、截止日期：必输项，凭证签收的日期。  
（2）账号：输入单位资金账户账号进行精确检索。  
（3）机构号：输入网点机构号进行精确检索。  
（4）行政区划：输入行政区划号码进行精确检索。  
（5）凭证号：输入8220-单位资金支付凭证号码进行精确检索。

其中：
	1、行政区划 为列表，参考其它的前端vue页面
	2、机构号 为列表，参考其它的前端vue页面

页面上操作有：

| 查询  |     | 按钮  | 点击按钮，根据输入查询条件查询列表数据         |
| --- | --- | --- | --------------------------- |
| 导出  |     | 按钮  | 点击按钮，导出报表                   |
| 重置  |     | 按钮  | 点击按钮，清空输入查询条件至默认查询条件并刷新列表数据 |
